# Resume Screening Assistant

An HR decision-support agent that compares resumes with declared job requirements and prepares an evidence-based recruiter summary.

## Workflow

1. Receive a job description, screening criteria, and resume.
2. Extract job-related qualifications and resume evidence.
3. Identify matches, gaps, uncertainty, and verification questions.
4. Send the summary to a human recruiter for the final decision.

## Passport Files

This repository includes `agent.yaml`, `SOUL.md`, and `EXPLAINABILITY.md` in the root folder.
